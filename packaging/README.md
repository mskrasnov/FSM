# Package build automatization scripts

> **Note:** In this directory, build scripts are organized not by package type (deb, rpm, AppImage), but by the distribution on which these packages are built.

## Debian

- **OS:** Debian 11
- **Supported packages build:**
  - `deb` (amd64, i686, aarch64)
  - `AppImage` (via [appimage-builder](https://github.com/appimagecrafters/appimage-builder); amd64 only)

## Fedora

- **OS:** Fedora 42
- **Supported packages build:**
  - `rpm` (amd64 only)
